
# 👁️ VisionGuard: macOS Eye Protection

VisionGuard is a premium, macOS-styled productivity tool designed to combat digital eye strain using the **20-20-20 Rule**. Every 20 minutes, it prompts you to look at something 20 feet away for 20 seconds.

## 🚀 Quick Start for Mac

### 1. Create your Repository
1. Go to [GitHub.com](https://github.com) and create a new repository named `vision-guard`.
2. Upload all files from this project to the repository.
3. Ensure your main branch is named `main`.

### 2. Enable GitHub Pages
1. In your GitHub repository, go to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. The app will now deploy automatically! Once finished, GitHub will provide a URL (e.g., `https://yourusername.github.io/vision-guard/`).

### 3. Install as a Mac App
1. Open your **GitHub Pages URL** in **Safari**.
2. Go to the top menu bar and select **File > Add to Dock...**.
3. Name it "VisionGuard" and click **Add**.
4. You now have a native-feeling VisionGuard app in your Mac Dock!

## ✨ Features
- **20-20-20 Timer**: Automates the scientifically backed eye-care routine.
- **macOS Design**: High-quality glassmorphism UI with native animations.
- **AI Wellness Tips**: Powered by Gemini 3 Flash for intelligent eye-care advice.
- **System Notifications**: Sends macOS native alerts even when minimized.
- **Quick Test**: Instantly verify animations and sounds.

## 🛠️ Technology Stack
- **React 19**: Modern UI rendering.
- **Google Gemini API**: Intelligent content generation.
- **Tailwind CSS**: Precision styling and responsiveness.
- **Web Audio API**: Custom frequency-based alert tones.

## 🔒 Security
The app requires an API Key for the Gemini AI features. Ensure `process.env.API_KEY` is configured in your deployment environment if you wish to use the AI wellness tips.
